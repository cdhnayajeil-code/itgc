ERP **공지사항**(1축)과 **패치관리 ZK4001M1**(2축) **두 개만** 놓고 대사한다.
패치 안의 **DLL 변경내역**과 **SQL 변경내역**은 서로 섞지 않고 따로 관리한다.

- 기간: **2026-01-01 ~ 2026-09-17**
- **DB 접속 없음.** `..\패치 및 프로시저 정리 통합\10_원천\` 에 이미 추출돼 있는 CSV만 읽었다(원천 폴더는 읽기만 하고 고치지 않음).
- 결과물: **`index.html`** 한 장이면 끝. 표 데이터는 `data\*.csv` 로도 나온다.

## 보는 법 — 공지에서 시작해 눌러서 들어간다

`index.html` 을 더블클릭하면 **공지 목록**이 먼저 뜬다.

```
① 공지 목록 (기본 화면)
      │  공지 행을 클릭
      ▼
   공지 상세 — 공지 본문(ERP 공지사항 화면) + 연결된 패치 카드
      │  패치 카드를 클릭
      ▼
   패치 상세 — 패치 머리부 + 패치내용 + ZK4001M1 화면 캡처 + DLL 내역 + SQL 내역
```

되돌아갈 때는 상세 왼쪽 위 `← 공지 목록` / `← 공지 NN` 을 누른다(브라우저 뒤로가기도 된다).

| 탭 | 내용 |
|---|---|
| **① 공지사항 12** | **기본 화면.** 2026년 등록 공지 12건 → 행 클릭 시 공지 상세 |
| **② 패치관리 39** | 패치 목록(별도 탭) → 행 클릭 시 패치 상세 |
| **DLL 36** | 패치에 포함된 `.dll` 전체. 패치번호를 누르면 그 패치 상세로 |
| **SQL 716** | 패치에 포함된 `.sql` 전체 (`공지등록 SQL` 표시 있음) |
| **대사결과** | 대사 규칙 · 수치 · 확인 필요 · 공지 없는 패치 26건 |

목록마다 **필터 칩 + 검색창 + CSV 내려받기**가 있다. 브라우저 인쇄(Ctrl+P)하면 목록들이 순서대로 나온다(상세는 인쇄 제외).

화면은 **숫자와 링크만 남기고 설명 문구를 덜어냈다.** 아래 내용은 화면에 없으니 여기서 본다.

- 상단 카드 5개 = 공지 12 / 패치 39 / DLL 36 / SQL 716 / 적용 오류추정 2
- 공지 12건 = 원천세 9 · 부가세 3, DLL 36건 = UI 35 · BL 1 (전부 TAX 모듈)
- DLL/SQL 수 = 패치 파일관리 탭의 실제 파일을 **확장자로 센 값**
- DLL 목록의 `파일수정일` = 벤더가 빌드한 시각이라 배포일보다 앞선다
- 패치 39건 전부 ZK4001M1 화면 캡처와 **일치**(화면=DB 검증, 원천 `20260917_화면`)
- 목록의 미대사 사유는 줄여 적었다 — 전체 문장은 `data\미대사_패치.csv` 에 있다

## 대사 규칙 (핵심)

패치에 들어 있는 **공지등록 SQL 파일명**과 **공지 제목**이 같은 키를 갖는다.

| 구분 | 공지 제목 | 패치 안의 SQL 파일 |
|---|---|---|
| 원천세 | `[2026-09-16]` | `040_homepage_ins_b_notice_tax_`**`20260916`**`.sql` |
| 부가세 | `[202607]` | `040_homepage_ins_b_notice_tax_`**`202607`**`.sql` |

날짜 근접이 아니라 **파일명 키**가 기준이라, 같은 공지에 후속 패치가 붙는 1:N 도 그대로 잡힌다.
